# Practical Coding Gym Guide

## Goal

Practice practical coding, Git, command-line usage, testing, and PR-style review.

## Workflow

For each problem:

1. Start from `main`
2. Create a new branch
3. Read the problem README
4. Implement from scratch with minimal starter code
5. Add my own tests
6. Run provided tests
7. Commit in logical checkpoints
8. Push the branch
9. Open a PR
10. Send the PR URL to ChatGPT for review

## Challenge Structure

Each problem should include:

- `README.md` with requirements
- `fixtures/` with input files
- `tests/` with provided tests
- minimal or empty `src/` so I implement from scratch

## Requirement Levels

Each problem should be staged:

- Level 1: MVP
- Level 2: edge cases
- Level 3: senior-level follow-ups

## Review Expectations

ChatGPT should review for:

- correctness
- edge cases
- code organization
- tests
- error handling
- Git hygiene
- senior-level judgment
- overengineering or underengineering

## Important Preference

Keep starter implementation code minimal. I want to practice creating files, structuring code, and implementing from scratch.
